  - [ ] Référencées dans le texte
  - [ ] Résolution suffisante (images nettes)

## 🎤 **2. PRÉSENTATION ORALE**

### Support de Présentation

- [ ] **Diaporama (PowerPoint/Google Slides)** :
  - [ ] 15-20 diapositives maximum
  - [ ] Diapo 1 : Page de titre (titre projet, nom, date)
  - [ ] Diapo 2 : Plan de la présentation
  - [ ] Diapo 3-4 : Contexte et problématique
  - [ ] Diapo 5-6 : Objectifs et méthodologie
  - [ ] Diapo 7-10 : Architecture et conception
  - [ ] Diapo 11-14 : Réalisation (captures d'écran, démo)
  - [ ] Diapo 15-17 : Tests et résultats
  - [ ] Diapo 18 : Conclusion et perspectives
  - [ ] Diapo 19 : Merci / Questions

- [ ] **Design professionnel** :
  - [ ] Template cohérent avec couleurs Dräxlmaier (bleu/gris)
  - [ ] Texte lisible (pas de surcharge)
  - [ ] Bullet points courts (6-7 par diapo max)
  - [ ] Images et diagrammes de qualité
  - [ ] Numérotation des diapositives

### Préparation de la Démo

- [ ] **Application fonctionnelle** :
  - [ ] Backend déployé sur Render.com (actif)
  - [ ] Application mobile installée et opérationnelle
  - [ ] Données de test créées (utilisateurs, messages, objectifs)
  - [ ] Scénario de démonstration préparé

- [ ] **Scénario de démo** (5-7 minutes) :
  - [ ] Connexion d'un employé
  - [ ] Affichage des objectifs
  - [ ] Envoi d'un message de groupe
  - [ ] Consultation des notifications
  - [ ] Affichage de la géolocalisation (Google Maps)

- [ ] **Backup prévu** :
  - [ ] Vidéo de démonstration (en cas de problème réseau)
  - [ ] Captures d'écran haute résolution
  - [ ] Émulateur Android installé (plan B)

### Répétitions

- [ ] **Répétition chronométrée** :
  - [ ] Durée totale : 15-20 minutes maximum
  - [ ] Introduction : 2 minutes
  - [ ] Corps : 10-12 minutes
  - [ ] Démo : 5-7 minutes
  - [ ] Conclusion : 1-2 minutes
  - [ ] Temps pour questions : 5-10 minutes

- [ ] **Entraînement** :
  - [ ] Au moins 3 répétitions complètes
  - [ ] Devant un public (famille, amis)
  - [ ] Feedback reçu et intégré
  - [ ] Gestion du stress travaillée

### Anticipation des Questions

- [ ] **Questions techniques** :
  - [ ] Pourquoi Flutter et non React Native ?
  - [ ] Pourquoi MongoDB et non PostgreSQL ?
  - [ ] Comment gérez-vous la sécurité (JWT, HTTPS) ?
  - [ ] Quels tests avez-vous effectués ?
  - [ ] Quelle est la scalabilité de votre solution ?

- [ ] **Questions méthodologiques** :
  - [ ] Pourquoi Scrum ? Quels sprints ?
  - [ ] Quelles difficultés rencontrées ?
  - [ ] Comment avez-vous priorisé les fonctionnalités ?

- [ ] **Questions sur les choix** :
  - [ ] Pourquoi Render.com et non AWS/Azure ?
  - [ ] Pourquoi Socket.IO pour le temps réel ?
  - [ ] Quelles alternatives avez-vous étudiées ?
